# BuildClock

BuildClock is a construction workforce management application built with Next.js, TypeScript, and Tailwind CSS.

The application is designed to help construction companies manage employees, track work hours, monitor job sites, organize schedules, and estimate payroll.

## Features

- Employee management
- Construction job-site tracking
- Employee work-hour tracking
- Overtime calculations
- Employee pay rates
- Weekly reports and timesheets

## Technology

- Next.js
- TypeScript
- Tailwind CSS
- React

## Getting Started

First, install the project dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser to view BuildClock.
